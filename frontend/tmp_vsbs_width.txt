2. In _lightbox-mobile.scss, if the file is a global SCSS file imported via @import, do NOT use :global(...) wrappers. :global() only works inside Vue SFC <style scoped> blocks. Since _lightbox-mobile.scss is imported via @import in a <style scoped> block, the :global() calls may NOT actually apply to teleported DOM elements outside the component's scoped tree.

This is likely the ROOT CAUSE: The :global() CSS selectors work within the component tree, but when BottomSheet teleports to body, the [data-vsbs-*] elements are OUTSIDE the Vue component's scope. Scoped styles with :global() may not reach teleported nodes.

Fix: Move the VSBS styles to a file that applies globally. Options:
a) Add the VSBS overrides to an existing global stylesheet (not scoped), like _lightbox-shared.scss
b) In LightboxMobileSheet.vue's <style> block (which is scoped), use :deep() instead of :global() for the teleported elements. BUT :deep() also has limitations with teleport.
c) The SAFEST fix: add a non-scoped <style> block to LightboxMobileSheet.vue for VSBS overrides.

Try option (c): add a second <style> block WITHOUT scoped for VSBS overrides:
