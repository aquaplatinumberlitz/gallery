### TanStack Virtual docs to follow:
- `@tanstack/vue-virtual` — https://tanstack.com/virtual/latest/docs/framework/vue/vue-virtual
- Vue adapter: `useVirtualizer` from `@tanstack/vue-virtual`
- `const rowVirtualizer = useVirtualizer({ count, getScrollElement, estimateSize, overscan, getItemKey })`
- `rowVirtualizer.getVirtualItems()` returns `VirtualItem[]` with `{ index, key, start, size, end, lane }`
- `rowVirtualizer.getTotalSize()` returns total scroll content size
- HTML structure:
  - Outer scroll container: `<div ref="scrollParentRef" style="overflow:auto; height:100%">`
  - Inside: header content (normal flow), then virtual spacer container:
    - `<div style={{ height: getTotalSize(), position: 'relative' }}>`
    - Inside that: each virtual row as `<div style={{ position: 'absolute', top: 0, transform: `translateY(${start}px)` }}>`
  - Then footer content (normal flow)

### Target structure for template:

```
<div class="scroller-container" :ref="setGridRef">
  <!-- Desktop/Tablet: TanStack Virtual -->
  <div v-if="!props.isMobile && imageRows.length > 0"
       ref="scrollParentRef"
       class="scroller tanstack-scroller"
       :class="{ 'fade-slide': !isMobile }"
  >
    <!-- BEFORE content (normal flow, outside virtual spacer) -->
    <GlowContainer v-if="folders.length" :disabled="false">
      <AlbumScroller :folders="folders" @open-folder="handleOpenFolder" />
    </GlowContainer>
    <GallerySectionHeader v-if="images.length" ... />

    <!-- Virtual spacer + rows -->
    <div class="tanstack-virtual-spacer" :style="{ height: rowVirtualizer.getTotalSize() + 'px', position: 'relative' }">
      <div
        v-for="virtualRow in rowVirtualizer.getVirtualItems()"
        :key="virtualRow.key"
        class="virtual-row tanstack-virtual-row"
        :style="{
          position: 'absolute',
          top: 0,
          left: 0,
          width: '100%',

          :key="img.path"
          :src="img.path"
          :name="img.name"

        />
      </div>
    </div>

    <div class="scroller-footer" :class="{ 'bars-hidden': !barsVisible }">
      <div ref="loadMoreSentinel" class="load-more-sentinel"></div>

    ...same as current...
  </div>

  <!-- Fallback: folders only -->
  <div v-else-if="folders.length > 0" ...>
    ...same as current...
  </div>
</div>
```

```typescript
const rowVirtualizer = useVirtualizer({
  count: imageRows.value.length,
  getScrollElement: () => scrollParentRef.value,
  estimateSize: () => rowHeight.value,
  overscan: 5,
  getItemKey: (index: number) => imageRows.value[index]?.id ?? index,
})
```

Note: In Vue adapter, options need to be reactive. If imageRows/rowHeight change, the virtualizer needs to re-measure. Use `watch` + `rowVirtualizer.measure()` when `rowHeight` or `columnCount` or `imageRows.length` changes.
