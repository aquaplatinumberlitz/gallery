## Library API (from docs)

Props: duration, snapPoints, initialSnapPoint, blocking (default true, enables focus trap), canSwipeClose, swipeCloseThreshold, canBackdropClose, expandOnContentDrag, modelValue (v-model), teleportTo (default 'body'), teleportDefer (Vue 3.5+, defer teleport until opened), headerClass, contentClass, footerClass, forceMount

Methods: open(), close(), snapToPoint(index)

Events: opened, opening-started, closed, closing-started, dragging-up, dragging-down, snapped(index), instinctHeight(height), update:modelValue

Key:
- blocking=false means: no backdrop, no focus trap, no ESC close, page remains scrollable
- teleportTo defaults to 'body'. Setting to false disables teleport (render in place).
- teleportDefer: defers teleport until sheet is opened (Vue 3.5+ — we have 3.5.24)
