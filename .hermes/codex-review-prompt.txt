--- AUDIT FINDINGS ---

**Issue 1 (P1): 110 dead re-exports in __init__.py**
Many symbols re-exported in __init__.py are NOT imported by any consumer outside metadata_store. Examples: `_cleanup_ignored_index_conn`, `_ensure_default_library_conn`, `_build_library_inspector_keyset_where`, etc. These are used internally within metadata_store modules already.
Fix: Remove dead re-exports from __init__.py.

**Issue 2 (P1): Mutable state copies in __init__.py**
`_DB_LOCK`, `_DB_INITIALIZED`, `_DB_INITIALIZED_PATH` are re-exported as `from ._db import X as X`. Since they're mutable singletons, assignment to them in the shim doesn't propagate to `_db.py`. Test patches already target `ms._db._DB_INITIALIZED` correctly, but the re-exports create a stale reference surface.
Fix: Either remove them from __init__.py (update all external consumers to use `ms._db.X`) or add a note that assignment doesn't propagate.

**Issue 3 (P2): PATH_SAFETY_ROOT flakes**
`PATH_SAFETY_ROOT` is a module-level variable in `backend/config.py` that defaults to `/`. Some tests mutate it without restoring, which could affect test isolation across test files.
Fix: Use monkeypatch or restore after each test.

**Issue 4 (P2): Late import in _asset_store.py**
`_find_library_for_path_conn` and `_library_exclusion_patterns_conn` are imported inside function body in `_upsert_asset_conn`:
```python
def _upsert_asset_conn(..., reactivate_existing: bool = True) -> int:
    from .library_store import _find_library_for_path_conn, _library_exclusion_patterns_conn
```
Fix: Move to top-level import. The late import was probably to avoid a cycle — confirm if a cycle exists.

**Issue 5 (P2): Misspelled function name in _schema.py**
`_rebuild_libraries_without_root_path` — typo "rebuild" vs "rebuild". Plan also uses this spelling.
Fix: Rename or note as intentional.
